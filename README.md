# Python for Data Science Fundamentals 🐍📊

A comprehensive collection of Jupyter Notebooks designed to take you from Python programming basics to foundational Machine Learning and Deep Learning concepts. This repository serves as a practical, hands-on guide for anyone looking to build a strong skill set in Data Science.

## 📚 Topics Covered

The repository is structured into progressive modules. Each topic includes explanatory notes, reproducible code examples, and practice exercises.

### 1. Python Core Concepts
* **Conditionals and Loops:** `if/elif/else` statements, `for` and `while` loops, list comprehensions, and control flow.
* **Functions:** Defining functions, positional and keyword arguments (`*args` and `**kwargs`), lambda functions, and variable scope.

### 2. File Handling & Data I/O
* Reading and writing local files (`.txt`, `.csv`, `.json`).
* Utilizing context managers (the `with` statement) for safe resource handling.
* Error and exception handling (`try/except`) during file operations.

### 3. Object-Oriented Programming (OOP)
* Classes, objects, attributes, and methods.
* Core principles: Inheritance, polymorphism, and encapsulation.
* Applying OOP concepts to structure custom data processing pipelines and model wrappers.

### 4. Essential Data Science Libraries
* **NumPy:** N-dimensional arrays, vectorized operations, and linear algebra fundamentals.
* **Pandas:** Series, DataFrames, data cleaning, handling missing values, filtering, grouping, and aggregation.
* **Matplotlib & Seaborn:** Data visualization, plotting distributions, correlation matrices, and exploratory data analysis (EDA).

### 5. Machine Learning
* Introduction to the `scikit-learn` API.
* **Supervised Learning:** Linear Regression, Logistic Regression, Decision Trees, and Random Forests.
* **Unsupervised Learning:** K-Means Clustering and Principal Component Analysis (PCA).
* Data preprocessing, train/test splits, cross-validation, and model evaluation metrics (Accuracy, F1-Score, RMSE).

### 6. Deep Learning
* Fundamentals of artificial neural networks.
* Forward and backward propagation concepts.
* Building and training Multi-Layer Perceptrons (MLPs) using [TensorFlow/Keras or PyTorch].
* Understanding activation functions, optimizers, and loss functions.
